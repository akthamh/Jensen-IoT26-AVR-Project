# Arduino Uno Bas-skelett IoT26 

This will be the base for the excercise in the course. Lots of christmas lights ;P

### Compiler and Simulation
We will use the AVR-GCC compiler for this project and simulate with wokwi in VS-code. Se the school portal for more information.

To compile:
```bash
make
```

To simulat, click the file diagram.json and then the play-button.

### VS-code
The .vscode allow us to point to the AVR library instead of the regular C-library. Make sure you have the correct path int the "includePath" directive. The avr-version probably will differ so make sure it has the correct version and correct path on your system.

### Interface
Basic knowlage of C is the only prerequisites needed. Use the interface to make stuff happen on the Arduino. Try out the example provided to get a hang on what we can do and then try to connect the functions in the example-function in the code.
